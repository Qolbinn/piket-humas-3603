# Design System

## Design Style
- Modern SaaS aesthetic
- Clean and minimal
- Spacious layout
- Professional but friendly

## Layout
- Mobile-first
- Responsive on all screen sizes
- Max content width: 1280px
- Use consistent spacing

## Components
- Use shadcn/ui as base
- Rounded corners: rounded-2xl
- Soft shadows
- Smooth hover transitions

## Colors
- Use neutral backgrounds
- Primary color : #0595d7
- Secondary color : #f7941d
- Third color : #8cc640

## Typography
- Clear visual hierarchy
- Large headings
- Comfortable reading width
- Avoid excessive font weights

## UX Rules
- Keep flows simple
- Minimize modal usage
- Prefer inline feedback
- Show loading states everywhere
- Show empty states where needed

## Tables
- Sticky headers when useful
- Responsive scrolling
- Search and filters preferred

## Forms
- Clear validation messages
- Labels always visible
- Large click targets

## Animations
- Subtle only
- Use motion for feedback, not decoration
- Keep animations under 300ms
